# Обязательные разделы диспетчерской панели

Источник: письмо с темой «скрин» от 27 мая 2026 года. В письме находятся 12 эталонных экранов прежней панели Aqua Delivery. Персональные данные со скриншотов в этот документ не переносятся.

## Обязательный состав

| Раздел | Обязательные элементы | Текущее состояние |
| --- | --- | --- |
| Заказы | Таблица, дата доставки, интервал, состав, водитель, статус, фильтры, сортировка, экспорт, новый заказ | Реализовано; экспорт CSV и рабочие фильтры добавлены |
| Маршрутные листы | Неразобранные, назначенные и недоставленные заказы; группировка по району и интервалу; назначение водителя | Реализовано на текущих заказах |
| Клиенты | ФИО, адрес, телефон, число заказов, последний заказ, оценка | Реализовано из истории заказов и оценок |
| Организации | Название, ИНН, КПП, долг по таре | Раздел реализован; до отдельного справочника показываются только подтвержденные договорные клиенты, ИНН/КПП/долг не выдумываются |
| Адреса | Клиент, район, адрес, координаты, фильтр адресов без координат | Реализовано из истории заказов |
| Водители | ФИО, телефон, рабочий статус, нагрузка и выполненные заказы | Реализовано |
| Оповещения | Хронология изменений по заказам | Реализовано из `order_events` |
| Чат | Список сообщений и карточка диалога | Системные сообщения реализованы из `order_events`; двусторонняя переписка требует провайдера сообщений |
| Обратная связь | Клиент, заказ, оценка, водитель, дата | Реализовано из `client_ratings` |
| Микромаркеты | Отдельный раздел контроля вендинговых точек | Раздел добавлен; реестр аппаратов требует отдельного источника данных |

## Дополнительное согласованное требование

- Карта зон доставки находится отдельно от маршрутных листов.
- Администратор может создавать, менять и удалять зоны.
- Диспетчер может только просматривать зоны и их настройки.
